# 📰 NOTICIAS-IA-TELEGRAM

Bot que envía noticias frescas de IA (traducidas al español) a tu Telegram,
ejecutándose en la nube cada 15 minutos vía GitHub Actions. Costo: $0.

## Seguridad
- Tus claves van en `.env` (local, ignorado por git) y en **GitHub Secrets** (en la nube).
- Ninguna clave aparece en el código ni se sube al repo.
